# v1.2.5 抢宿舍工具

## 版本信息
- **版本号**: 1.2.5
- **更新时间**: 2026-08-22
- **基于版本**: v1.2.4
- **主要优化**: 耗时优化（预启动worker、连接池、智能重试）

## 优化内容

### 1. 预启动worker优化
- **优化前**: worker在开放时间到达后才启动
- **优化后**: 在开放前1秒启动worker线程
- **效果**: 减少worker启动延迟，提高响应速度

### 2. 连接池优化
- **优化前**: 每次请求都建立新连接
- **优化后**: 使用连接池，复用连接
- **效果**: 减少连接建立时间，提高请求速度

### 3. 智能重试优化
- **优化前**: 固定重试间隔
- **优化后**: 根据错误类型智能调整重试间隔
- **效果**: 减少无效重试，提高抢购成功率

### 4. 开放时间检查
- **优化前**: worker启动时不检查开放时间
- **优化后**: worker启动时检查开放时间，未到时间则等待
- **效果**: 避免提前提交，减少507错误
