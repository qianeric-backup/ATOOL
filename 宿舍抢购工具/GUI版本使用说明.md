# V0.0.9b GUI版本使用说明

## 功能概述
- **功能**: 带有图形界面的多开抢购工具
- **版本**: V0.0.9b GUI版本
- **测试状态**: ✓ 测试通过

## 使用方法

### 1. 启动GUI
- **方法1**: 双击`releases/multi_instance_gui/multi_instance_gui.exe`
- **方法2**: 使用命令行
```bash
releases/multi_instance_gui/multi_instance_gui.exe
```

### 2. 配置账号信息
在GUI界面中：
1. 点击"添加账号"按钮
2. 输入录取通知书编号和身份证号
3. 输入账号名称（可选）
4. 点击"保存"

### 3. 配置抢购参数
在GUI界面中：
1. 设置提前毫秒数（默认300）
2. 设置最大重试次数（默认200）
3. 设置重试间隔毫秒数（默认200）
4. 设置并发数（默认1）

### 4. 开始抢购
点击"开始抢购"按钮，所有配置的账号将开始抢购

## 界面说明

### 1. 账号管理区域
- **添加账号**: 添加新的抢购账号

- **删除账号**: 删除已选中的账号
- **导入账号**: 从文件导入账号

### 2. 抢购设置区域
- **提前毫秒数**: 提前多少毫秒开始抢购
- **最大重试次数**: 最大重试次数
- **重试间隔毫秒数**: 重试间隔时间
- **并发数**: 并发线程数

### 3. 操作按钮
- **开始抢购**: 启动所有账号抢购
- **停止**: 停止所有抢购（待实现）
- **保存配置**: 保存当前配置到文件
- **加载配置**: 从文件加载配置

### 4. 状态栏
- 显示当前操作状态

## 故障排除

### 1. GUI无法启动
- **检查**: 确认tkinter模块可用
- **解决**: 安装Python（包含tkinter）

### 2. 配置文件不存在
- **检查**: 确认`config_multi.json`文件存在
- **解决**: 创建配置文件或使用GUI加载

### 3. V0.0.9版本exe不存在
- **检查**: 确认`grab_dorm.exe`文件存在
- **解决**: 确保V0.0.9版本已正确安装

### 4. 启动失败
- **检查**: 检查账号信息是否正确
- **解决**: 确认enrollid和idcard格式正确
