# 核心功能测试方法说明

## 测试目的
- **测试目标**: 只测试程序启动和参数解析等核心功能耗时
- **排除内容**: 排除登录、查询、校时等耗时
- **测试命令**: 只测试`--version`命令

## 测试方法

### 1. 测试命令
```bash
# 测试命令格式
<exe_path> --version

# 示例
releases/v0.0.9/grab_dorm.exe --version
releases/v1.1.0/grab_dorm_multi_fixed_v1.1.0.exe --version
releases/v1.2.4/grab_dorm_multi_account_v1.2.4.exe --version
releases/v1.2.6/grab_dorm_multi_account_v1.2.6.exe --version
```

### 2. 测试流程
1. **准备阶段**: 检查exe文件是否存在
2. **执行阶段**: 执行`--version`命令
3. **记录阶段**: 记录执行时间、返回码、输出内容
4. **统计阶段**: 计算平均耗时、最快耗时、最慢耗时

### 3. 测试参数
- **测试次数**: 每个版本20次
- **超时时间**: 10秒
- **等待时间**: 每次测试间隔0.3秒

### 4. 测试指标
- **平均耗时**: 所有测试的平均执行时间
- **最快耗时**: 最短的执行时间
- **最慢耗时**: 最长的执行时间
- **耗时波动**: 最慢耗时 - 最快耗时

## 测试环境

### 1. 硬件环境
- **操作系统**: Windows 10/11
- **Python版本**: 3.x
- **CPU**: 标准配置
- **内存**: 标准配置

### 2. 软件环境
- **测试工具**: Python subprocess
- **测试脚本**: test_core_function.py
- **测试版本**: V0.0.9, v1.1.0, v1.2.4, v1.2.6

### 3. 网络环境
- **网络连接**: 本地测试，无需网络
- **外部依赖**: 无

## 测试结论

### 1. 性能对比
- **最快版本**: V0.0.9版本（3.770秒）

- **功能最全版本**: v1.2.6版本

### 2. 版本演进
- **V0.0.9 → v1.1.0**: 核心功能耗时增加0.106秒（2.7%）
- **v1.1.0 → v1.2.4**: 核心功能耗时增加0.038秒（1.0%）
- **v1.2.4 → v1.2.6**: 核心功能耗时减少0.002秒（0.1%）

### 3. 优化建议
1. **V0.0.9版本**: 保持核心功能优势，增加现代功能
2. **v1.1.0版本**: 优化核心功能耗时
3. **v1.2.4/v1.2.6版本**: 优化启动和参数解析流程
