# cppTickerBuy 使用说明（本机打包版）

## 已交付文件

| 文件 | 说明 |
|---|---|
| `cppTickerBuy.exe` | 打包好的可执行文件（约 72MB，单文件，双击即用） |
| `repo/` | 项目源码（含构建环境 `.venv`） |

## 运行方法

1. 双击 `cppTickerBuy.exe` 运行（首次启动约 30~60 秒，会解压运行环境）。
2. 终端出现 `Running on local URL: http://127.0.0.1:7860` 后，浏览器打开该地址即可使用。
3. 程序自带 5 个标签页：**配置 / 抢票 / 查看订单 / 登录管理 / 常见问题**。
4. 抢票成功后会有付款二维码与提示音。
5. 关闭终端窗口即退出程序。

> 💡 **若页面显示的还是旧界面**：浏览器会缓存页面，请按 `Ctrl+Shift+R` 强制刷新，或直接开一个**无痕/隐身窗口**访问 `http://127.0.0.1:7860`。

## Web 登录（v2 新增）

不再需要切到终端输入账号。在「登录管理」页直接：
1. 输入 **手机号** 和 **密码**
2. 点 **「登录」** 按钮
3. 页面「输出信息」显示"✅ 登录成功！下一步：前往「配置」页…"即完成，并会提示下一步操作

> 也可点「导入登录信息文件」加载已有的登录文件。登录态（含明文密码）保存在 exe 同目录 `cookies.json`，注意保管。

## 分步操作提示（v2 新增）

每个页面在完成一步后都会提示下一步：
- **登录管理**：登录成功 → 提示前往「配置」页
- **配置**：获取票信息成功 → 提示勾选购票人、选票、生成配置；生成配置成功 → 提示前往「抢票」页
- **抢票**：填入配置后自动提示选择开抢时间并点「开始抢票」；页面顶部常驻"①填配置 → ②选时间 → ③设参数 → ④开始抢票"步骤条

## 本机构建记录（已在 Python 3.12 / Windows 验证）

官方工作流（GitHub Actions）用的是 Python 3.11 + `pyinstaller~=5.13.2` + `main.spec`，本机按同样流程构建，并对 **Python 3.12 兼容性**做了最小改动：

### 源码改动（4 处）

| 文件 | 改动 |
|---|---|
| `requirements.txt` | 移除 `playsound~=1.3.0`（Python 3.12 无法构建；它只被无效的 `__main__` 测试分支引用，不影响功能） |
| `util/PushPlusUtil.py` | 删除 `import playsound` 及无效的 `__main__` 测试块 |
| `util/ServerChanUtil.py` | 删除未使用的 `import playsound` |
| `main.py` | 启动前设置 `no_proxy=127.0.0.1,localhost`，防止配置了系统代理时 gradio 误判 localhost 不可达 |

### 构建环境版本固定（重要）

pip 默认会把依赖解析到 2026 年最新版，与 2024 年的 gradio 4.44.1 不兼容，需固定为：

```bash
pip install "setuptools>=68,<81"        # 保留 pkg_resources（PyInstaller 5.x 需要）
pip install "numpy==1.26.4"             # 与 PyInstaller 5.13 兼容（2.x 会缺 _exceptions）
pip install "huggingface-hub==0.25.2"   # 新版本移除了 gradio 用的 HfFolder
pip install "fastapi==0.115.0" "uvicorn==0.30.6"  # 新版 starlette 与 gradio 4.44 不兼容
```

构建命令：

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt pyinstaller~=5.13.2
.venv/Scripts/pyinstaller main.spec --noconfirm
# 产物：dist/cppTickerBuy.exe
```

### 验证结果

- exe 启动后进程正常存活（约 184MB 内存）；
- `http://127.0.0.1:7860` 返回 HTTP 200；
- 页面包含全部 UI 标签：配置 / 抢票 / 查看订单 / 登录管理 / 常见问题；
- NTP 时间同步功能正常（连接 ntp.aliyun.com 成功）。
