# 同类抢票/票务自动化软件推荐

> 按"目标平台"分类整理，均已核实仓库存在。这些工具大多处于灰色地带（违反平台服务条款、可能触发风控/封号），**仅供学习研究，请遵守平台规则与当地法律，切勿商业盈利**。

## 🎪 CPP 漫展（allcpp.cn）专用

| 项目 | 语言 | 特点 |
|---|---|---|
| **cppTickerBuy**（本项目） | Python + gradio | 图形化 Web 界面，对小白友好，作者已归档 |
| [Koileo/ticket_for_allcpp](https://github.com/Koileo/ticket_for_allcpp) | Python | 多线程暴力抢票，命令行 + cookie 配置，已归档 |
| [FairyWorld/ticket_ticket_for_allcpp](https://github.com/FairyWorld/ticket_ticket_for_allcpp) | Python | cppTickerBuy 的衍生，多线程暴力抢票，图形化 |

## 📺 B站会员购（BW/BML/CP 等，show.bilibili.com）

| 项目 | 语言 | 特点 |
|---|---|---|
| [mikumifa/biliTickerBuy](https://github.com/mikumifa/biliTickerBuy) | Python | cppTickerBuy 同作者的前作，B站会员购抢票，教程文档完善 |
| [miaowuawa/MyGO](https://github.com/miaowuawa/MyGO) | Python | biliTickerBuy 的后续维护版，提供官方 ctoken API 服务 |
| [Violiate/bili_ticket_rush](https://github.com/Violiate/bili_ticket_rush) | Rust | 跨平台 GUI，多账号/多购票人，定时抢票+捡漏模式，风控处理完善 |
| [Oecxuan/2233TicketBuy](https://github.com/Oecxuan/2233TicketBuy) | Python | 扫码登录、双服务器校时、蹲票模式、412/429 智能降速，出 Windows exe |

## 🎤 演唱会票务（大麦 / 猫眼 / 票星球 / 淘票票）

| 项目 | 语言 | 特点 |
|---|---|---|
| [TsungShr/ticket-sniper](https://github.com/TsungShr/ticket-sniper) | Python | 三平台并发（票星球 API 直连 + 猫眼/大麦 ADB 自动化），NTP 毫秒级校时，Bark/ServerChan 通知 |
| [zhushuaifeifei/damaihelper](https://github.com/zhushuaifeifei/damaihelper) | Python | 大麦/淘票票/缤玩岛，Web 控制台 + YOLO 滑块识别，默认 dry-run，偏学习联调 |
| [Guyungy/damaihelper](https://github.com/Guyungy/damaihelper) | Python | 上述 damaihelper 的同名衍生版本 |

## 💡 选择建议

- 只想用现成的：cppTickerBuy（本项目 exe）已可直接运行；B站场景优先 `bili_ticket_rush`（Rust GUI、最活跃）。
- 想自己改/学：`biliTickerBuy` 教程文档最全；`ticket-sniper` 架构最清晰（平台抽象 + 并发协调）。
- 已归档仓库（cppTickerBuy、ticket_for_allcpp、MyGO）请留意依赖兼容性与风险提示。

## ⚠️ 统一提醒

1. 抢票软件普遍违反平台用户协议，可能触发验证码/风控/封号，成功率无保证。
2. 请勿使用任何工具进行加价倒卖（我国《治安管理处罚法》对倒卖有价票证有处罚规定）。
3. 使用任何工具前，请自行确认其最新状态、许可证与免责声明。
