建桥学院抢课助手

选课系统：EAMS · 四步抢课 · 配置可导入导出 · 支持多开

操作手册

一、总览

本助手连接上海建桥学院 EAMS 选课系统（eams.gench.edu.cn），用于选课开放时段快速抢课。所有人工操作都在页面输入框内完成。

二、四步使用流程

  1. 1. 登录：输入学号 + EAMS 密码登录，或粘贴浏览器里的 EAMS Cookie（任意有效会话 Cookie 均可，选课 token 会自动换取）。登录后顶部状态栏显示" 已登录"。
  2. 2. 选课轮次：点「 刷新轮次」载入当前开放的选课轮次。若显示红色提示"当前没有开放轮次"，说明选课尚未开始或已结束。
  3. 3. 目标课程：点「 载入课程」列出可选课程，点击选中目标课程（可用搜索框按课程名/代码筛选）。
  4. 4. 抢课控制：设置开抢时间（留空=立即）、间隔（秒）、最多次数，点「 开始抢课」。到点自动高频提交选课请求，日志实时显示过程与结果。

三、登录的两种方式

  • 账密登录：输入学号 + EAMS 密码（若从未改过，可能是初始密码或门户密码）。
  • Cookie 登录（F12 抓取步骤，推荐）：浏览器登录一次 EAMS 后，按下 F12 → Network → 勾选 Preserve log（保留日志）→ 刷新页面 → 在列表中找到任意 eams.gench.edu.cn 的请求（例如 /student/home/menu）→ 点击它 → 在 Request Headers 中找到 cookie: 一整行，整行复制（形如：SESSION=...; __pstsid__=...; wel_userid=...; cs-course-select-student-token=eyJ...）→ 粘贴到登录卡片的 Cookie 输入框。其中 cs-course-select-student-token=eyJ... 就是选课 token（JWT），脚本会自动识别并使用；只要 Cookie 属于有效 EAMS 会话（SESSION 或 token 任一）即可，之后轮次/课程/抢课自动运行。

四、配置导入导出

在"1. 登录"卡片底部：

  • 导出配置：把 学号/密码/Cookie/轮次/目标课程/开抢时间/间隔 保存为 抢课配置_时间戳.json（文件名带导出时间，已登录时自动包含当前会话 Cookie）。
  • 导入配置：选择之前导出的 json 文件，自动回填所有输入框，一键复用。

五、注意事项

  • 抢课是写操作：只有你点「开始抢课」才会提交选课请求，脚本不会自动抢。
  • 间隔建议 ≥ 0.2 秒，避免对服务器造成压力或触发风控。
  • Cookie 时效（重要）：选课 token（cs-course-select-student-token）有效期约 12 小时，SESSION 通常更短。到期后无法登录/刷新轮次，页面会提示"Cookie 已失效"。建议每次抢课前 30 分钟内重新按 F12 步骤获取最新 Cookie，避免到点才发现过期。
  • 密码与 Cookie 仅在本机使用，不写入文件（除非你主动导出配置）。
  • 抢到课后请到 EAMS 官网确认课表，以官方数据为准。
